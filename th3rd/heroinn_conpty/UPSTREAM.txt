The crate is vendored from the complete 0.7.0 production source tree. Upstream
CI files and integration-test fixtures are omitted. The crate-level Cargo.lock
is retained for the standalone Windows regression suite.

Local changes:

1. Cargo.toml: publish = false; the local workspace's minimum Rust version is
   recorded; windows 0.54.0 is pinned and Win32_UI_WindowsAndMessaging is
   enabled for the hidden-console fix.
2. src/process.rs::stdout_handle: when the GUI-subsystem process cannot attach
   to a parent console, allocate a console and hide its window before opening
   CONOUT$. This preserves the old Heroinn GUI-subsystem behavior while using
   windows 0.54 APIs.
3. tests/heroinn_conpty.rs and examples/windows_subsystem.rs: Heroinn-native
   regression coverage for interactive cmd startup, I/O, resize, exit,
   cross-thread lifetime/reclamation, repeated lifecycle, and the hidden
   console.
4. src/io/reader.rs: remove an unnecessary unsafe block required for a
   warning-free Windows build with the workspace toolchain.

No upstream resource-cleanup workaround from the old 0.3.0 fork is retained.
